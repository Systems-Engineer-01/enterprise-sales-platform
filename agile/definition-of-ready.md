# Definition of Ready

A Product Backlog Item is Ready for Sprint Planning when:

- [ ] The business objective is understood.
- [ ] The user/persona is identified.
- [ ] The requirement is clearly described.
- [ ] Acceptance criteria are defined.
- [ ] Dependencies are identified.
- [ ] Technical uncertainty has been sufficiently investigated.
- [ ] The item can reasonably be completed within a Sprint.
- [ ] The item provides identifiable value or enables required
      technical capability.
- [ ] Required designs or decisions are available.
